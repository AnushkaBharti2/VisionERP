# Contributing to VisionERP

1. Create a feature branch from `main`.
2. Keep changes focused and documented.
3. Add or update tests for backend behavior.
4. Run the frontend build and Python syntax checks locally.
5. Never commit secrets, credentials, personal data or biometric samples.
6. Open a pull request describing the problem, implementation and test evidence.

## Commit style
Prefer clear imperative commits such as `Add visitor approval workflow` or `Harden JWT configuration`.
